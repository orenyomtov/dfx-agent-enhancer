What the rack shows

Pick a window: 5 MIN, 1H, TODAY (the default, from midnight) or WEEK. Hover anything for the exact numbers.

  • GraphSpend in dollars per hour across every Claude Code session and subagent, or how many sessions are active. Switch with SPEND / SESSIONS.
  • SessionsAgents working now, or with activity in the window.
  • SubagentsTask and workflow agents, and Cursor subagents.
  • Spend · Tool callsTotals for the window, on the old EQ sliders and 7-segment digits. Spend is approximate: the usage your transcripts record, at Anthropic's API list prices.
  • ErrorsAPI errors and failed turns. The LED goes red for 15 minutes.
  • ChimePlays a sound when an agent finishes. Off by default.

One-line install

macOS only. Turn launch at login on or off from the menu-bar menu.

·
$ curl -fsSL https://raw.githubusercontent.com/orenyomtov/dfx-agent-enhancer/main/install.sh | bash

Installs to /Applications and starts at login.

1 Download the DMG. Drag the app into Applications. 2 Open it once, then System Settings > Privacy & Security > Open Anyway.

The app isn't notarized, so macOS asks once. The terminal install skips this step.

Download DMG View on GitHub

To uninstall, run the same command with bash -s -- --uninstall in place of bash.
